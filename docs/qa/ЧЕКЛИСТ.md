# Чеклист Infinity Music — все функции и приоритеты

ТЗ владельца 25.09: «чек-листы по функциям и приоритетам, чтобы знать, на
сколько они готовы, — надо на 100%». Роль проверяющего — жёсткий тестировщик
и нетерпеливый пользователь: ждать 5 секунд не станет, лаги и кривые плашки не
простит.

**Как читать**

| знак | значит |
|---|---|
| ✅ | проверено ВЖИВУЮ (реальный Telegram / прод) и работает |
| 🟢 | покрыто тестами, вживую ещё не прожато |
| 🔴 | найден баг — ссылка на исправление рядом |
| ⬜ | не проверялось |
| ➖ | сознательно не проверяется (оплата, рассылка всем, каналы подписки) |

Готовность считается честно: **только ✅ идут в процент.** 🟢 — это «код
работает в тестах», а не «человек доволен».
