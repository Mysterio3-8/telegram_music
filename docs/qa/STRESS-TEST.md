## Правила прохода (решения владельца 13.09)

- **Нагрузка — только локально.** Прод (1 ядро, 961 МБ) уже падал от нагрузки.
  На прод можно только мягкие пробы по HTTPS и чтение журналов.
- Найденное чинить, покрывать тестом и деплоить.
- **Пэйвол Mini App остаётся клиентским** (решение владельца): API Premium не
  проверяет. Это не баг прохода, в отчёт — «известный риск».
- Потолок одного переноса плейлиста — 1000 треков.
- Свайп вниз = «Назад» на вложенных экранах — ТЗ §3 владельца, не трогать.

### Решения владельца 14.09 (Infinity QA v2.0 — бесконечный цикл)

Перекрывают правила 13.09 там, где противоречат.

- **Режим:** итерации в одной сессии; к ~50% контекста всё записано в файлы,
  владелец делает compact, цикл продолжается. Журнал итераций — раздел
  «Журнал циклов» в конце этого файла.
- **Деплой без подтверждения**, но только после полного pytest. Увидел ошибки
  пользователей на проде после выкатки — откат (`git reset` на прошлый

- **Пэйвол закрывается на сервере.** Без Premium в API доступны только вход,
  оплата, профиль, документы. Бот не трогается. Админы и триал проходят.
- **Нагрузка на прод разрешена** — только в ночное окно 03:00–05:00 МСК,
  без рассылки пользователям, короткими заходами; при росте ошибок — стоп и

- **Мониторинг:** ошибки 5xx и исключения — в журнал и сводкой владельцу в
