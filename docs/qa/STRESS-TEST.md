## Мягкая проба прода (без нагрузки)

```bash
for p in / /src/main.js /nonexistent /.git/config /.env /api/health /api/track/1 /webhook/yookassa; do printf "%-20s " "$p"; curl -s -o /dev/null -w "%{http_code} %{size_download}B %{time_total}s\n" -H "Accept-Encoding: gzip" "https://keybest.cc$p"; done
curl -sI https://keybest.cc/ | grep -iE "^(server|strict|x-content|referrer|cache)"
```

Ожидание: сканерные пути — 404, `Server: nginx` без версии, есть
`Strict-Transport-Security`, `main.js` сжат (~17 КБ). В этой сборке curl нет
`--http2`: HTTP/2 проверять по конфигу (`listen 443 ssl http2`).
