# ФИНАЛЬНЫЙ ГЕЙТ ПЕРЕД РЕЛИЗОМ

Заполняется перед деплоем крупной функции. Каждая строка — `✓`, `✗` или
`UNKNOWN + причина`. **`✓` без выполненной проверки запрещён.**

```
ФУНКЦИОНАЛЬНОСТЬ
[ ] Заявленное работает — проверено, а не «должно работать»
[ ] Граничные значения входа проверены
[ ] Неявные требования дописаны и подтверждены владельцем

ДОСТУП
[ ] Личность вычисляется сервером
[ ] Права проверяются на уровне ресурса (владение), а не только «залогинен»
[ ] Чужой ресурс → 404
[ ] Публичные эндпоинты перечислены и обоснованы
[ ] Тест «пользователь A не получает ресурс B» существует

ВХОД
[ ] Валидация на сервере по всем полям
[ ] Потолки: тело, строка, массив, page_size, файл
[ ] Мусор (null/[]/-1/огромное/чужой тип) даёт 400, а не 500

ЦЕЛОСТНОСТЬ
[ ] Гонки проверены на операциях начисления/создания
[ ] Уникальность обеспечена БД, а не проверкой перед вставкой
[ ] Повтор операции безопасен (вебхук, задача, кнопка)
[ ] Транзакции корректны; внешние вызовы вне транзакций

ДЕНЬГИ (если затронуты)
[ ] Сумма/срок/валюта только с сервера
[ ] Текст пользователю совпадает со списанием
[ ] Вебхук: подлинность + перепроверка у API + идемпотентность
[ ] Журнал операций пополняется ровно один раз на платёж
[ ] Живой платёж проверен реальной картой

СЕКРЕТЫ
[ ] Нет во фронте, логах, образе, ответах, истории git
[ ] Сравнение секретов постоянное по времени
[ ] Подписанные ссылки имеют срок

ОТКАЗЫ
[ ] Отказ отличим от пустого результата
[ ] Отказ не кэшируется как отрицательный ответ
[ ] Поведение при недоступности каждой зависимости определено
[ ] Наружу не уходит трассировка, SQL, пути

НАГРУЗКА
[ ] Планы запросов проверены, нет N+1 и полных сканов
[ ] Лимиты частоты и бизнес-лимиты на месте
[ ] Счётчики лимитов убираются, память не течёт
[ ] Тяжёлое вынесено в очередь

ФРОНТ
[ ] Состояния: загрузка, пусто, ошибка, офлайн, медленно
[ ] Двойной клик безопасен
[ ] Экранирование чужого текста
[ ] Узкий экран, обе темы, длинные строки
[ ] Заголовки безопасности, CORS не «*»

TELEGRAM
[ ] initData: подпись, затем свежесть; тесты на подделку
[ ] callback_data проверяется как недоверенный вход
[ ] Антифлуд первым в цепочке
[ ] file_id: самолечение работает во всех ветках выдачи
[ ] Гейт подписки: сбой API ≠ «не подписан»

ЭКСПЛУАТАЦИЯ
[ ] Миграции применены и проверены на копии прода
[ ] Известно, что не доезжает обычным деплоем (юниты, конфиг веб-сервера)
[ ] Логи без секретов, ротация есть
[ ] Алерты покрывают: сервис упал, работа стоит, диск, память, 5xx, платежи
[ ] Бэкап вне сервера, восстановление проверено
[ ] Откат возможен

ТЕСТЫ
[ ] Зелёные на всех платформах, где запускаются
[ ] На каждую найденную в этой сессии дыру есть тест
[ ] CI блокирует деплой при красных

ЮРИДИЧЕСКОЕ (перед публичным запуском и при смене региона)
[ ] Инвентаризация данных актуальна
[ ] Документы доступны до оплаты
[ ] Права пользователя реализованы технически
[ ] Канал для жалоб правообладателей работает

ЗАКРЫТИЕ
[ ] PROJECT-STATUS.md обновлён
[ ] LESSONS.md пополнен
[ ] NEWS.md: пост о релизе (правило проекта)
```

## Как докладывать результат

```
РЕЛИЗ: <что>
Пройдено: N пунктов
Не пройдено: список с severity
UNKNOWN: список с причинами
Решение: деплоим / не деплоим / деплоим с оговоркой <какой>
```

Если есть хоть один `CRITICAL` — не деплоим. `HIGH` — деплоим только с явного
решения владельца, и оно записывается.
