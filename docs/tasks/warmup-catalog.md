# Прогрев каталога

**Статус:** 🟡 CLI готов и задеплоен, ждём накопления запросов
**Из чек-листа:** [CHECKLIST.md](../../CHECKLIST.md) → «В работе»

## Зачем

Поиск занимает 0.22 сек, но если трека нет в базе — его надо скачать, а это ещё
7-14 сек, и предел тут ставит источник. Уже заминченный трек уходит мгновенно, по
`file_id`, вообще без сети. Значит единственный способ дать «мгновенно» —
иметь трек заранее.

## Что готово

`python -m app.cli.warmup` — идемпотентен, пауза 4 сек между треками, гейт по
свободному диску, режим `--dry`.

    python -m app.cli.warmup --popular 300        # по реальным запросам людей
    python -m app.cli.warmup --file queries.txt   # свой список

Запросы из бота теперь пишутся в `search_queries` — `--popular` работает.

## Потолки (замерено)

Аудио хранит Telegram, наш диск оно не занимает. Упираемся в другое:

| Что | Сколько |
|---|---|
| База | ~9 КБ на трек (7240 треков = 65 МБ) |
| 100 тысяч треков | ≈ 900 МБ базы — влезает |
| Миллион | ≈ 9 ГБ базы при 7.6 ГБ свободных — **не влезет** |
| Темп | ~15 треков/мин (лимит Telegram) → миллион больше месяца |
| Трафик | миллион × ~3 МБ ≈ 3 ТБ через VPS |

**Реалистичная цель: десятки тысяч популярных.** Длинный хвост закрывает живой поиск.
