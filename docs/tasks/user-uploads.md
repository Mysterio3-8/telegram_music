# Загрузка своих треков — сделать удобной

**Статус:** ⚪ идея владельца, ТЗ не подтверждено
**Из чек-листа:** [CHECKLIST.md](../../CHECKLIST.md) → «Дальше по плану»

## Зачем

Владелец хочет, чтобы пользователи сами пополняли базу — это и рост каталога, и
вовлечение. Сейчас мастер загрузки работает, но неудобен.

## Что просил владелец

- Пачка из нескольких файлов сразу — **но он же сам склонился к «по одному лучше»**:
  пачка всё равно не вся загрузится (DRM, копирайт), и разбирать отказы сложнее
- При загрузке дать указать **исполнителя**
- Дать приложить **обложку** — или явно выбрать «без обложки»

## Как сейчас

Мастер: файл → название → исполнитель → подтверждение. Исполнитель уже
спрашивается. Обложки нет — берётся из метаданных файла, если есть.

## Что реально доделать

1. **Шаг обложки**: приложить картинку или пропустить
2. **Понятные отказы**: сейчас при неудаче человек видит текст ошибки без подсказки
3. Решить про пачку — по итогам разговора склоняемся к «по одному»

## Решение владельца (08.08)

**Обложку можно пропустить** — шаг необязательный. Нет обложки → берём из
метаданных файла, если там есть; иначе оставляем пустой.
