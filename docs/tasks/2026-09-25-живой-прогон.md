# Спека сессии: живой прогон бота и Mini App

Владелец 25.09: «сделай спеку для сессии, только для прогона бота и аппа».
Одна задача на сессию — пройти бота @muz_damn_bot и Mini App руками, как
нетерпеливый пользователь, найти всё кривое и сразу починить. Больше ничего:
нагрузочный тест, дизайн по скринам ВК, рефакторинг и бизнес-статистика — не
сюда.

## Как заходить

- Telegram Desktop на компьютере владельца, через управление компьютером
  (`mcp__computer-use__*`): `request_access` → Telegram. Владелец уже вошёл.
- Встроенный браузер на web.telegram.org не пускает, расширения Chrome нет —
  на них время не тратить.
- Mini App открывается кнопкой «🎧 Открыть плеер» в чате бота (внутри Telegram
  Desktop, это окно Telegram — доступ тот же).
- Параллельно из Bash можно смотреть прод: `journalctl -u tg-music-bot / -api`
  по SSH (команда — в CLAUDE.md). Каждое найденное «тормозит / не пришло»
  сверять с журналом, а не гадать.

## Что можно и что нельзя

| можно | нельзя |
|---|---|
| писать боту, жать любые кнопки | нажимать оплату (ЮKassa, звёзды, TON, карта) — только до экрана оплаты |
| Mini App целиком | рассылку `adm:bcast*` |
| админку бота: смотреть, модерация, правка метаданных | каналы подписки `adm:subch*` |
| добавлять треки себе в библиотеку и плейлисты | удаление `adm:junk:go`, `adm:clip:go`, `adm:reclaim:go`, слияние дублей |
| | писать кому-то кроме бота; открывать чужие чаты |
| | ссылки из сообщений кликать мышью (правило безопасности) |

После прогона убрать за собой: тестовые плейлисты и треки, добавленные только
ради проверки.

## Порядок (по приоритетам владельца)

Отметки ставятся прямо в [qa/ЧЕКЛИСТ.md](../qa/ЧЕКЛИСТ.md): ✅ только за то,
что прожато вживую; нашёл баг — 🔴 и ссылка на коммит.

1. **Скорость — главное.** Засекать по часам на скриншотах:
   - ответ бота на текст (список) — цель ≤ 2 сек;
   - трек, которого нет в базе, — ≤ 5 сек; уже в базе — мгновенно;
   - открытие Mini App до первого нажатия — ≤ 1.5 сек;
   - старт Infinity Mix и `play-live` — ≤ 2 сек.
   Всё, что дольше, — баг, даже если «в итоге работает».
2. **Бот, раздел 1 чеклиста** — 1.2 быстрый поиск (кириллица, латиница,
   транслит, опечатка, одно слово, только артист, ссылка SoundCloud/YouTube),
   1.3 карточка, 1.1 старт и язык ×7, 1.4 библиотека и плейлисты, 1.5 минусы,
   1.6 перенос (Spotify и Яндекс — ссылкой), 1.7 деньги до экрана оплаты,
   1.8 рефералка, 1.9 инлайн (в «Избранном»), 1.10 админка без запретного.
3. **Mini App, раздел 2 чеклиста** — старт, главная, поиск, плеер (все
   кнопки, свайпы, фон), мини-плеер, библиотека, карточка артиста (Chief Keef,
   Playboi Carti), профиль, настройки, документы (читать глазами на смысл),
   Premium до оплаты.
4. **Треки в базу** — после тапа по одному треку проверить на проде, что
   заминчена вся выдача (до 20), а в чат пришёл один; название «Исполнитель —
   Название» без мусора; обложка в чате и в плеере чёткая.
5. **Адаптация** — окно Telegram Desktop узкое (≈ телефон) и широкое
   (компьютер): кривые плашки, наложения, обрезанный текст, горизонтальная
   прокрутка. Кривое записывать в
   [чеклист дизайна](2026-09-24-чеклист-дизайн.md), чинить — только если
   сломано (наложение, не нажать), а не «некрасиво».

## Нашёл баг — что делать

1. Скриншот «было» — в `docs/посты/скрины/` (пойдёт в пост «до/после»).
2. Причина по коду и журналу, не догадкой.
3. Исправление + тест, который падает без исправления.
4. Полный `pytest -q > файл 2>&1; echo EXIT=$?` — зелёный.
5. Для Mini App — `python tools/build_miniapp.py`, иначе прод не увидит правку.
6. Коммит → push в main (автодеплой, журнал
   `/var/lib/tg-music-deploy/history.log`) → проверить вживую тем же путём →
   скриншот «стало».
7. Упал прод после выката — откат, потом разбираться.

Партиями: несколько мелких правок — один коммит, но не копить до конца сессии.
