# Минусы: починить и собрать базу

**Статус:** 🟡 парсер готов и работает, идёт полный импорт
**Из чек-листа:** [CHECKLIST.md](../../CHECKLIST.md) → «Болит сейчас»

Владелец называет минусы своей уникальностью: этого нет у конкурентов.
Сейчас направление нерабочее.

## Что замерено на проде (08.08)

| Показатель | Значение |
|---|---|
| Минусов в базе | 42 |
| Из них с `tg_file_id` | **0** |
| Источников ТГ-каналов | 1 |

**Отправить нельзя ни одного.** Выдача минуса идёт по `tg_file_id`, а его нет ни
у одного — поэтому «поиск минусов не работает» даже когда поиск находит.
Сначала чинить доставку, потом наполнять базу.

Названия в базе: `DJ Kale — AUTUM Cm 136bpm @djkale`, `DJ Kale — BELLS` — то
есть без пометки «минус», ровно как описал владелец.

## Идея владельца

1. **Парсить не из ТГ-канала, а с YouTube.** В канале названия без пометки, и
   добавлять её вручную неудобно. На YouTube пометка есть в самом названии.
2. **Парсер берёт только то, где в названии есть маркер** — «минус»,
   «instrumental», «karaoke», «backing track», «prod. by» и т.п. На канале
   владельца лежат и обычные видео, их брать не надо.
3. **Отдельная база и отдельная поисковая строка** — минусы это отдельный вид,
   не смешивать с треками (так и сделано: таблица `instrumentals`).
4. **В боте:** человек пишет «минус kizaru long way» → приходит минус.
5. **В Mini App:** есть переключатель на минусы, поэтому префикс не нужен —
   пишешь «kizaru long way», получаешь файл, подписанный «Минус — …».

## Решения владельца (08.08)

1. **Канал:** [@MinusZvyaaga](https://www.youtube.com/@MinusZvyaaga), 525 видео
2. **Маркеры не нужны:** канал чисто минусовой, у каждого видео префикс «МИНУС -»
   и «(Instrumental)» — берём всё подряд. Ключ `--only-marked` оставлен для
   смешанных каналов на будущее
3. **42 старых удалены** — у всех был пустой `tg_file_id`, отправить их было
   нельзя, терять нечего
4. **Минусы бесплатны для всех.** Гейтов Premium на них в коде нет — менять
   ничего не потребовалось

## Как запускать

    python -m app.cli.import_minuses --channel <ссылка> --dry     # посмотреть
    python -m app.cli.import_minuses --channel <ссылка>           # боевой
    python -m app.cli.import_minuses --channel <ссылка> --only-marked  # смешанный канал

Идемпотентен, пауза 4 сек, гейт по диску. Лог полного прогона:
`/var/log/tg-music-minuses.log`

⚠️ Источник минусов из ТГ-канала (`telegram_channel_sources` с
`target=instrumentals`) остался включён — он и дальше будет тащить минусы без
пометки в названии. Решить, отключать ли его.
