# Мониторинг памяти и диска

**Статус:** ⚪ не начато
**Из чек-листа:** [CHECKLIST.md](../../CHECKLIST.md) → «Болит сейчас»

## Зачем

Про проблемы с ресурсами узнаём, только когда владелец пишет «бот тормозит».
Так было четырежды: 26.07 (диск 100%), 01.08 (воркер в OOM-петле), 03.08
(массовый парсер подняли руками, память 883 из 961 МБ), 07.08 (падение хостера).
Каждый раз симптом доходил до пользователей раньше, чем до нас.

## Что сделать

Лёгкий скрипт раз в 5-10 минут (systemd timer):
- `free` → при доступной памяти < 150 МБ шлём владельцу алерт в Telegram
- `df /` → при свободном месте < 500 МБ то же самое
- `redis-cli llen <очередь>` → при росте очереди выше порога

⚠️ Размер очередей Redis стеречь обязательно: дважды именно они съедали память, а
`ps` про это врёт — Redis уходит в своп и в списке процессов выглядит безобидно
(`used_memory_human` 724 МБ при `rss` 5.88 МБ).

## Как слать

У бота есть токен и ADMIN_IDS — достаточно `send_message` первому админу.
Отдельный процесс не нужен, хватит скрипта на bash + curl к Bot API.

## Не забыть

- Алерт не чаще раза в 30 минут, иначе при затяжной проблеме получится флуд
- Скрипт сам должен быть лёгким: никакого Python с импортом SQLAlchemy
