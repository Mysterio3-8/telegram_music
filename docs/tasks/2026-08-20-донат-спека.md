# Спека: донат + скрытие Mini App (20.08.2026)

Запрос владельца, одобрен к исполнению без согласований. Решения владельца,
принятые до начала работы: **оплата идёт в личке бота** (в канале — кнопка-ссылка),
**цель сбора одна** (активная).

## 1. Что делаем

1. **Донат в боте**: кнопка в главном меню + команда `/donate` + deep-link
   `?start=donate` (по нему приходят из канала).
2. **Суммы**: 49 / 229 / 499 / 1099 ₽ + своя сумма (10…100 000 ₽).
3. **Способы**: ⭐ Stars, 💳 рубли (ЮKassa), 💎 TON. Stars и TON пересчитываются
   из рублёвой суммы по курсу — «примерно», как просил владелец.
4. **Цель сбора**: админ задаёт название и сумму, на экране доната виден прогресс.
5. **Кнопка к постам канала**: админ либо публикует новый пост с кнопкой, либо
   цепляет кнопку к уже опубликованному посту по ссылке на него.
6. **Mini App спрятан** от всех, кроме админов (временно, решение владельца).

## 2. Данные

`donation_goals` — цель сбора (история хранится, активная одна):
`id, title, target_rub, is_active, created_at, closed_at`.

`donations` — намерение задонатить и его судьба:
`id, user_id, goal_id, amount_rub, amount_stars, amount_nano_ton, method,
status(pending|paid), ref, charge_id, created_at, paid_at`.

⚠️ `amount_rub` заполняется ВСЕГДА, даже когда платят звёздами или TON: человек
выбирает сумму в рублях, а звёзды/TON — только рельсы. Иначе прогресс цели
пришлось бы складывать из трёх валют, а это число ничего не значит (ровно та же
причина, по которой `Payment` держит рубли и звёзды в разных колонках).

⚠️ Донаты НЕ пишутся в `payments`: там выручка с Premium, и подмешивание туда
подарков сделало бы отчёт о продажах неправдой. У донатов свой блок в админке.

## 3. Оплата

- **Stars** — `answer_invoice` в XTR, payload `donate:{id}`. `pre_checkout` и
  `successful_payment` донатов ловит отдельный роутер, зарегистрированный ДО
  `premium.router` (у того обработчики без фильтра по payload).
- **ЮKassa** — платёж с `metadata.kind = "donation"`; webhook ветвится по этому
  полю, иначе донат активировал бы Premium.
- **TON** — адрес кошелька + сумма + уникальный комментарий (`ref`). Подтверждение
  — сверка входящих транзакций через toncenter: по кнопке «Я отправил» сразу и
  ночным проходом в обслуживании. Пусто `TON_WALLET_ADDRESS`/`TON_RUB_PER_TON` →
  способ не показывается (сейчас на проде так).

## 4. Гейт подписки

`don:*`, `/donate` и `/start donate` — **вне гейта обязательной подписки**.
Человек, который пришёл из канала отдать деньги, не должен упираться в требование
подписаться: это единственное действие, где отказ стоит дороже, чем пропуск.

## 5. Mini App

- WebApp-кнопка в меню и кнопка-меню чата (`MenuButtonWebApp`) — только админам;
  остальным дефолтная кнопка команд. Питч плеера в кабинете заменён на строку про
  поддержку проекта.
- API и пэйвол не трогаем: у кого есть прямая ссылка и оплаченный Premium — тот
  продолжает пользоваться. Это скрытие входа, а не блокировка (владелец сказал
  «временно спрятать»).
- Из Mini App убраны промо-карточки «купить Premium» (главная, библиотека,
  профиль, тексты): за пэйволом их видит только тот, кто УЖЕ оплатил, — то есть
  никто. Покупка живёт на пэйволе, продление — в настройках.

## 6. Проверка

Тесты на: цель (одна активная, прогресс), суммы и своя сумма (границы),
пересчёт в звёзды и TON, ветвление webhook ЮKassa, сверка транзакции toncenter,
клавиатуры, скрытие плеера от не-админа, исключение доната из гейта.
